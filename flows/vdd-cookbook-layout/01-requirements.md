# Requirements: Cookbook Layout Migration

> Version: 1.0
> Status: APPROVED
> Last Updated: 2026-05-02

## Описание проблемы

Существует legacy iOS проект (Objective-C) книги рецептов/кулинарной книги с богатым функционалом: навигация по страницам, поиск, закладки, аудио плеер, анимации. Проект устарел и требует миграции на Flutter для:
- Кроссплатформенности (iOS + Android + Web)
- Современной архитектуры и поддержки
- Адаптивной верстки для разных размеров экранов

## User Stories

### Основные

**Как** пользователь
**Я хочу** листать страницы книги свайпами влево/вправо
**Чтобы** удобно читать книгу как бумажную

**Как** пользователь
**Я хочу** искать текст, заголовки и комментарии в книге
**Чтобы** быстро находить нужные рецепты

**Как** пользователь
**Я хочу** добавлять закладки на страницы
**Чтобы** сохранять любимые рецепты

**Как** пользователь
**Я хочу** слушать аудиосопровождение страниц
**Чтобы** воспринимать контент на слух

### Вторичные

**Как** пользователь
**Я хочу** видеть анимации на страницах (спрайты, fade, rotation)
**Чтобы** получать более интерактивный опыт

**Как** пользователь
**Я хочу** использовать интерактивные элементы управления
**Чтобы** переходить по ссылкам внутри книги

## Acceptance Criteria

### Must Have

1. **Given** приложение открыто
   **When** пользователь делает свайп влево/вправо
   **Then** происходит переход на следующую/предыдущую страницу с анимацией

2. **Given** страница книги отображается
   **When** страница содержит фоновое изображение
   **Then** изображение корректно масштабируется под размер экрана

3. **Given** пользователь открывает поиск
   **When** вводит текст запроса
   **Then** отображаются результаты поиска с выделением найденного текста

4. **Given** список закладок
   **When** пользователь нажимает на закладку
   **Then** происходит переход на сохраненную страницу

5. **Given** страница с аудио
   **When** пользователь нажимает Play
   **Then** аудио воспроизводится, прогресс отображается

6. **Given** разные размеры экранов (телефон, планшет, десктоп)
   **When** приложение открыто
   **Then** интерфейс адаптируется под размер экрана

### Should Have

1. **Given** страница с анимацией
   **When** страница загружена
   **Then** анимация автоматически запускается (если autostart=true)

2. **Given** элементы управления на странице
   **When** пользователь нажимает на контрол
   **Then** выполняется соответствующее действие (переход, play/stop и т.д.)

3. **Given** кастомный шрифт (Devanagari/Sanskrit)
   **When** текст использует этот шрифт
   **Then** текст отображается корректно

### Won't Have (в этой итерации)

- Редактирование контента книги
- Синхронизация закладок с облаком
- Офлайн загрузка дополнительных книг
- Push-уведомления
- Темная тема (возможно в следующей итерации)

## Constraints

- **Технические**: Flutter SDK 3.x, Dart 3.x
- **Платформы**: iOS 12+, Android 5.0+, Windows 10+, Linux, macOS 10.14+
- **Данные**: Существующий XML формат данных книги должен быть поддержан
- **Ресурсы**: ~441 изображений (~620MB), 5 обложек, 47 спрайтов анимации, 1 кастомный шрифт
- **Производительность**: Переход между страницами < 100ms, загрузка изображений с lazy loading

## Функционал из Legacy проекта

### Экраны

| Экран | Описание | Приоритет |
|-------|----------|-----------|
| Main View | Просмотр страниц с контентом, навигация | P0 |
| Search | Поиск по тексту/заголовкам/комментариям | P1 |

### Компоненты

| Компонент | Описание | Приоритет |
|-----------|----------|-----------|

- prev-page / next-page - навигация
- bookmarks / add-bookmark - закладки
- play-sound / stop-sound / toggle-player - аудио
- search - поиск
- page-link - переход на страницу
- toggle-animations - вкл/выкл анимации
