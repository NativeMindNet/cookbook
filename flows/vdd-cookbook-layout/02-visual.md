# Visual Mockups: Cookbook Layout Migration

> Version: 1.0
> Status: DRAFT
> Last Updated: 2026-05-02

## Обзор

ASCII макеты адаптивной верстки кулинарной книги для 5 платформ (iOS, Android, Windows, Linux, macOS) с поддержкой portrait и landscape ориентации.

---

## Адаптивные брейкпоинты

| Тип устройства | Ширина | Колонки | Пример |
|----------------|--------|---------|--------|
| Mobile | < 600px | 1 | iPhone, Android phone |
| Tablet | 600-1024px | 1-2 | iPad, Android tablet |
| Desktop | > 1024px | 2-3 | Windows, Linux, macOS |

---

## Компонент: Анимации

### Спрайтовая анимация

```
+----------------------+
|  Кадр 1  ->  Кадр 2  |
|    |          |      |
|    v          v      |
|  Кадр 3  ->  Кадр 4  |
|    |                 |
|    v                 |
|  ...   ->  Кадр 47   |
+----------------------+

Параметры:
- FPS: 24
- Loop: true/false
- Autostart: true/false
```

### Трансформации

```
Fade:     [|||] -> [||.] -> [|..] -> [...]
          alpha: 1.0 -> 0.0

Rotate:   [/] -> [-] -> [\] -> [|]
          0° -> 90° -> 180° -> 270°

Scale:    [.] -> [o] -> [O] -> [O]
          0.5x -> 1.0x -> 1.5x -> 2.0x
```

```

                                   v

      |                            |                            |
      |                            |                            |

+-------------+           +------------------+           +-------------+
|  Bookmarks  |           |   Audio Player   |           |  Search     |

       +----------------------> Переход на страницу <-----------+
```

### Жесты навигации

```
Main View:
- Свайп влево  -> Следующая страница
- Свайп вправо -> Предыдущая страница
- Свайп от края -> Открыть Drawer (на мобильных)
- Тап на контрол -> Действие контрола

Search:
- Тап на результат -> Переход на страницу с подсветкой

Bookmarks:
- Тап на закладку -> Переход на страницу
- Свайп влево -> Удалить закладку (iOS-style)
- Long press -> Режим редактирования
```

## Адаптивное поведение

### Breakpoint: Mobile (< 600px)

```
- Drawer: Выезжает слева поверх контента
- Навигация: Только через жесты и кнопки
- Аудио плеер: Внизу экрана (свернутый)
- Поиск: Полноэкранный модал
- Закладки: Полноэкранный модал
```

### Breakpoint: Tablet (600-1024px)

```
- Drawer: Выезжает слева поверх контента
- Навигация: Жесты + видимые кнопки по бокам
- Аудио плеер: Внизу экрана (расширенный)
- Поиск: Полноэкранный с 2 колонками результатов
- Закладки: Боковая панель справа
```

### Breakpoint: Desktop (> 1024px)

```
- Drawer: Фиксированный слева (всегда виден)
- Навигация: Жесты + большие кнопки по бокам
- Аудио плеер: В боковой панели
- Поиск: Модальное окно по центру
- Закладки: В левой панели под меню
- Два колоночный layout: контент + текст
```

## Заметки

- Все кнопки должны иметь минимальный размер 48x48dp для touch-friendly
- Шрифт Devanagari (MurariChandUni) используется для контента на хинди
- Анимации страниц: curl (iOS-style) или slide
- Изображения загружаются с lazy loading и кэшированием
- Landscape ориентация особенно важна для рабочего использования на кухне
