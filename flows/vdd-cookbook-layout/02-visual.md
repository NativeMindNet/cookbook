# Visual Mockups: Cookbook Layout Migration

> Version: 1.0
> Status: APPROVED
> Last Updated: 2026-05-02

## Обзор

ASCII макеты адаптивной верстки кулинарной книги для 5 платформ (iOS, Android, Windows, Linux, macOS) с поддержкой portrait и landscape ориентации.

---

## Адаптивные брейкпоинты

| Тип устройства | Ширина | Колонки | Пример |
|----------------|--------|---------|--------|
| Mobile | < 600px | 1 | iPhone, Android phone |
| Tablet | 600-1024px | 1-2 | iPad, Android tablet |
| Desktop | > 1024px | 2-3 | Windows, Linux, macOS |

---

## Компонент: Анимации

### Спрайтовая анимация

```
+----------------------+
|  Кадр 1  ->  Кадр 2  |
|    |          |      |
|    v          v      |
|  Кадр 3  ->  Кадр 4  |
|    |                 |
|    v                 |
|  ...   ->  Кадр 47   |
+----------------------+

Параметры:
- FPS: 24
- Loop: true/false
- Autostart: true/false
```

### Трансформации

```
Fade:     [|||] -> [||.] -> [|..] -> [...]
          alpha: 1.0 -> 0.0

Rotate:   [/] -> [-] -> [\] -> [|]
          0° -> 90° -> 180° -> 270°

Scale:    [.] -> [o] -> [O] -> [O]
          0.5x -> 1.0x -> 1.5x -> 2.0x
```

```
Main View:
- Свайп влево  -> Следующая страница
- Свайп вправо -> Предыдущая страница

- Тап на результат -> Переход на страницу с подсветкой

Bookmarks:
- Тап на закладку -> Переход на страницу
- Свайп влево -> Удалить закладку (iOS-style)
- Long press -> Режим редактирования
```

## Адаптивное поведение

### Breakpoint: Mobile (< 600px)

```
- Drawer: Выезжает слева поверх контента
- Навигация: Только через жесты и кнопки
- Аудио плеер: Внизу экрана (свернутый)
- Поиск: Полноэкранный модал
- Закладки: Полноэкранный модал
```

### Breakpoint: Tablet (600-1024px)

```
- Drawer: Выезжает слева поверх контента
- Навигация: Жесты + видимые кнопки по бокам
- Аудио плеер: Внизу экрана (расширенный)
- Поиск: Полноэкранный с 2 колонками результатов
- Закладки: Боковая панель справа
```

### Breakpoint: Desktop (> 1024px)

```
- Drawer: Фиксированный слева (всегда виден)
- Навигация: Жесты + большие кнопки по бокам
- Аудио плеер: В боковой панели
- Поиск: Модальное окно по центру
- Закладки: В левой панели под меню
- Два колоночный layout: контент + текст
```

## Заметки

- Все кнопки должны иметь минимальный размер 48x48dp для touch-friendly
- Шрифт Devanagari (MurariChandUni) используется для контента на хинди
- Анимации страниц: curl (iOS-style) или slide
- Изображения загружаются с lazy loading и кэшированием
- Landscape ориентация особенно важна для рабочего использования на кухне

## Глубокий анализ реализации

### Сильные стороны (Strengths)
1. **Адаптивность**: Использование `ResponsiveBreakpoints` и `TwoPageBookView` позволяет приложению корректно переключаться между одностраничным и двухстраничным режимами.
2. **Чистота кода**: Логика UI отделена от бизнес-логики через Bloc (`BookBloc`, `BookmarksBloc`).
3. **Навигация по тапам**: В `BookPageView` реализована удобная навигация: тап по левой трети — назад, по правой — вперед.
4. **Централизованное управление темой**: Цвета и шрифты вынесены в `main.dart` (ThemeData).

### Отклонения от изначальных спецификаций (Discrepancies)
1. **Desktop Layout**: В спецификации §2.4 указан фиксированный Drawer слева для Desktop, в коде же используется стандартный выезжающий `Scaffold.drawer`.
2. **Контролы**: Индикатор прогресса реализован как `LinearProgressIndicator` внизу экрана, а не горизонтальный ползунок в центре. Отсутствует кнопка справки `[?]` и кнопки быстрой навигации `[<<][>>]` на оверлее (навигация реализована через невидимые зоны тапа).
3. **Состояние "Аудио"**: В коде `MainScreen` пока нет интеграции с `AudioBloc` для отображения прогресса воспроизведения, хотя сам `AudioBloc` существует.
4. **Визуал Drawer**: Отсутствует аватар пользователя/статус гостя, указанный в макетах.
5. **Региональные настройки (§7.5 SDD)**: В макете зафиксированы **четыре** дропдауна (язык, меры, система измерений, нумерация). В коде (`AppDrawer`) реализован только выбор **языка**; дропдауны «Меры», «Система измерений» и «Нумерация» отсутствуют до расширения `SettingsBloc` и данных `measures.json`.

### Технический долг и рекомендации
1. **Интеграция XML**: `BookRepository` пока использует плейсхолдеры для страниц. Необходимо внедрить `XmlBookParser`.
2. **Overlay Controls**: Желательно добавить анимацию появления/исчезновения контролов (сейчас используется `AnimatedOpacity`).
3. **Поиск**: `SearchBloc` готов, но `SearchScreen` требует проверки на соответствие визуальным макетам (вкладки "Текст", "Заголовки", "Заметки").
4. **Четыре дропдауна в Drawer**: Добавить в настройки поля профиля мер (`measureSet`), системы измерений (`unitSystem`) и набора цифр для чисел (`numeralSet`: arabic / thai / chinese), персистентность в `SharedPreferences`, UI по макету выше; связать с экраном мер, будущим `UnitFormatter` и форматированием чисел в UI (см. SDD §7.5).
