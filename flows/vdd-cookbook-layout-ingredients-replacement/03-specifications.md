# Спецификации: мастер замены ингредиентов

> Версия: 1.0  
> Статус: DRAFT  
> Обновлено: 2026-05-02  
> Визуал: [02-visual.md](./02-visual.md)

## Обзор

Изолированный модуль UI + данных для справочника замен. Использует те же декоративные примитивы, что и `vdd-cookbook-layout-cook` (`ParchmentPanel`, `BambooRodHeader`), чтобы визуально быть частью книги.

## Модель данных

### IngredientReplacementEntry

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | `String` | Стабильный ключ |
| `title` | `String` | Заголовок (напр. «Кокосовое молоко») |
| `body` | `String` | Основной текст; допускается подмножество Markdown или форматированный `List<InlineSpan>` из CMS |
| `aliases` | `List<String>` | Для поиска («кокос», «coconut milk») |
| `columnHint` | `int {0,1}` | На широком экране: левая (0) или правая (1) колонка для сохранения порядка референса |
| `order` | `int` | Сортировка внутри колонки |

Хранение: `assets/data/ingredient_replacements.json` (или слайс из общего XML книги, если переносят контент).

## Навигация

| Маршрут | Экран |
|---------|-------|
| `/book/ingredients` | Шаг 1: поиск |
| `/book/ingredients/:id` | Шаг 2: деталь одной записи (опционально) |
| `/book/ingredients/browse` | Шаг 2-alt: полный разворот всех записей скроллом (если продукт решит без отдельного detail route) |

Рекомендация: для соответствия референсу **один экран разворота со всеми блоками** + **якорная прокрутка** при выборе из списка (deep link `...?focus=id`). Альтернатива — показывать только выбранный блок и «соседей» в той же колонке.

## Поиск

- Нормализация: lower case, trim, возможно ударения игнорировать.
- Ранжирование: точное вхождение в `title` выше, затем `aliases`, затем `body`.

## Доступность

- Поле поиска с `semanticLabel`.
- Маркер-декор помечать как `excludeFromSemantics: true`, текст заголовка — в семантике.

## Зависимости

- `vdd-cookbook-layout-cook` — вход из меню.
- Локализация: ключи ARB для заголовков экрана и пустых состояний.
