# Мастер замены ингредиентов (VDD)

## Что это

Отдельный сценарий справочника: пользователь ищет ингредиент и читает рекомендуемые замены и комментарии, в оформлении разворота книги (пергамент, бамбук, маркеры у блоков).

Это **не** вкладка **«Ингредиенты»** внутри раздела кухни — та описана в **`flows/vdd-cookbook-layout-ingredients/`** (иллюстрированный перечень продуктов региона).

## Откуда открывается

Из главного меню книги (**«Замена ингредиентов»**) по потоку **`vdd-cookbook-layout-cook`**.

## Связь с общим ридером

После выхода назад пользователь возвращается в меню книги или стек навигации приложения; общий просмотр рецептов описан в **`vdd-cookbook-layout`**.
