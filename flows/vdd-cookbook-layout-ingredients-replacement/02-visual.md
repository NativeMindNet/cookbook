## Обзор потока

Мастер замены ингредиентов — справочник для поиска альтернатив продуктам. Два основных шага:

1. **Поиск** — список всех ингредиентов с возможностью фильтрации
2. **Деталь** — разворот пергамента с текстами замен

---

## Поток навигации

```
[Главное меню B] ──«Замена ингредиентов»──> [Шаг 1: Поиск]
                                                  |
                                            тап на строку
                                                  v
                                            [Шаг 2: Деталь]
                                                  |
                                              [< Назад]
                                                  v
                                            [Шаг 1: Поиск]
```

## Компонент: Строка списка ингредиента

```
+-----------------------------------------------+
| ❀  Название ингредиента                     > |
+-----------------------------------------------+

- ❀ — декоративный маркер слева
- Название — жирный текст
- > — индикатор навигации справа
- Фон: чередование (зебра) или единый пергамент
- Высота строки: ~48-56dp
- Отступы: 16dp по горизонтали
```

---

## Компонент: Поле поиска

```
+------------------------------------------+
| +--------------------------------------+ |
| | 🔍  Поиск по названию...             | |
| +--------------------------------------+ |
+------------------------------------------+

- Иконка лупы слева
- Placeholder: «Поиск по названию...»
- При вводе: фильтрация списка в реальном времени
- Кнопка очистки (×) справа при наличии текста
```

## Адаптивность

| Breakpoint | Колонки списка | Колонки детали | Поведение |
|------------|----------------|----------------|-----------|
| < 600px (mobile) | 1 | 1 | Вертикальный скролл |
| 600-1024px (tablet) | 2 | 2 | Разворот пергамента |
| > 1024px (desktop) | 2 | 2 | Разворот, max-width контента |
