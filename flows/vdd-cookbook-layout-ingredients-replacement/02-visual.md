## Общая логика мастера

Два шага:

1. **Выбор** — поиск + список.
2. **Деталь** — разворот пергамента с текстами замен (как референс); на телефоне одна колонка с сохранением порядка блоков слева→направо как на развороте.

```
[Меню книги] --«Замена ингредиентов»--> [Шаг 1 Поиск]
                                           |
                                    выбор строки
                                           v
                                      [Шаг 2 Деталь]
                                           |
                                        [Назад]
                                           v
                                      [Шаг 1 Поиск]
```

## Экран 2: Деталь замен (планшет / две колонки)

Упрощённо соответствует референсу: слева блоки 1–N, справа продолжение.

```
+------------------------------------------+
| [<] Замена ингредиентов                  |
| === бамбук + кольца =====================|
| +-------------------+-------------------+|
| | [ фото блюда ]    |                   ||
| |                   |                   ||
| | ЗАМЕНА            | * Лук-порей       ||
| | ИНГРЕДИЕНТОВ      |   текст замены... ||
| |                   |                   ||
| | * Рафинированный  | * Арахис          ||
| |   сахар           |   текст...        ||
| |   замена: мёд,    |                   ||
| |   агава...        | * Рыбный соус     ||
| |                   |   текст...        ||
| | * Лук-шалот       | * Грибной соус    ||
| |   текст...        |   текст...        ||
| |                   | * Кокосовое молоко||
| |                   |   длинный абзац...||
| +-------------------+-------------------+|
+------------------------------------------+
```

Легенда:

- `*` — декоративный маркер (иконка «цветок» из референса).
- Первая строка блока после маркера — **название жирным**.

## Экран 2: Деталь (мобильный, одна колонка)

Порядок блоков: как на развороте слева сверху → слева снизу → затем правая колонка сверху вниз.

```
+------------------------------------------+
| [<] ...                                  |
| --- пергамент ----------------------------|
| [ фото ]                                 |
| ЗАМЕНА ИНГРЕДИЕНТОВ                      |
| * **Рафинированный сахар** ...           |
| * **Лук-шалот** ...                      |
| * **Лук-порей** ...                      |
| * **Арахис** ...                         |
| * **Рыбный соус** ...                    |
| * **Грибной соус** ...                   |
| * **Кокосовое молоко** ...               |
+------------------------------------------+
```
