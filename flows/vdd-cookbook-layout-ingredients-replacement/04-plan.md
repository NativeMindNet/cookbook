# План реализации: мастер замены ингредиентов

> Версия: 1.0  
> Статус: DRAFT  
> Обновлено: 2026-05-02  
> Спецификации: [03-specifications.md](./03-specifications.md)

## Кратко

Добавить JSON (или XML) с записями замен, экран поиска, экран разворота с форматированием; интегрировать маршруты в существующий `go_router`; переиспользовать декоративные виджеты книги.

## Задачи

| ID | Задача | Зависимости | Проверка |
|----|--------|-------------|----------|
| I1 | Схема данных + пример JSON из референса | — | Unit: парсинг |
| I2 | Репозиторий + поиск | I1 | Unit: фильтрация |
| I3 | UI: `IngredientReplacementSearchPage` | I2 | Widget тест списка |
| I4 | UI: `IngredientReplacementMasterPage` (разворот) | I2 | Golden / ручной скрин |
| I5 | Маршруты `/book/ingredients` | I3,I4 | Интеграция с меню cook |
| I6 | Локализация строк (RU + заготовки ключей) | I3,I4 | l10n генерируется |
| I7 | Якорная прокрутка `focus=id` | I4,I5 | Ручной тест deeplink |

## Риски

| Риск | Митигация |
|------|-----------|
| Дублирование декора | Вынести в общий пакет `lib/widgets/book_decor/` из задачи cook |

## Откат

Удалить маршруты и assets данных; меню ведёт в заглушку.
