## Цель

Перенести сущности из `02-specifications.md` в машиночитаемый формат (JSON/YAML/XML-расширение) и связать с маршрутами приложения и страницами `book.xml`.

## Задачи (черновик)

1. Таблица маппинга `intro.toc` ↔ `page` в `book.xml`.
2. Выгрузка таблицы мер в asset JSON + ключи локализации.
3. Импорт справочника замен (`repl.*`) — общий файл с `vdd-cookbook-layout-ingredients-replacement`.
4. Валидация: каждый `nav.*` имеет целевой экран или заглушку.
5. Маппинг **§13** (`cuisine.*`): вкладки, секции пергамента, элементы сетки и **пагинация** тайских списков ↔ узлы `book.xml` / индекс оглавления.

6. Маппинг **§14** (`ing.book.indian.*`) ↔ страницы/якоря в `book.xml`; поля `title_en_parenthetical`, `layout.book.indian_ingredients.*`, привязка `measure.inline.*` из §7.4 к фрагментам XML при необходимости структурированного рецептурного парсинга.
