# Требования: экран «Ингредиенты» в разделе региональной кухни

> Версия: 1.0  
> Статус: DRAFT  
> Обновлено: 2026-05-02  
> Язык: русский

## Проблема

В хабе каждой кухни по макетам книги есть вкладка **«Ингредиенты»** со списком продуктов в виде сетки карточек (фото + подпись). Этот экран **отличается по смыслу** от мастера **«Замена ингредиентов»** в главном меню и должен иметь отдельную спецификацию: состав данных, пагинация, локализация.

## Пользовательские истории

**Как** читатель  
**Я хочу** открыть вкладку **Ингредиенты** в разделе Индийской / Китайской / Японской / Тайской кухни  
**Чтобы** просмотреть иллюстрированный перечень характерных продуктов этой кухни в оформлении книги

**Как** читатель  
**Я хочу** видеть **ту же шапку и вкладки**, что и на экранах блюд выбранной кухни  
**Чтобы** не терять контекст навигации

**Как** читатель  
**Я хочу** при длинном списке переключать **страницы** стрелками и подписью «N из M», где это предусмотрено книгой  
**Чтобы** экран не перегружался на маленьком устройстве

### Не входит

- Редактирование списка пользователем.
- Поиск по ингредиентам в первой версии (желательно — см. ниже).
- Экран мастера замен (**`vdd-cookbook-layout-ingredients-replacement`**).

## Критерии приёмки

### Обязательно

1. **Given** пользователь в хабе одной из четырёх кухонь  
   **When** выбрана вкладка с идентификатором «ингредиенты»  
   **Then** отображаются: строка серии «Вегетарианская кухня Востока», бамбук, **цветной баннер названия кухни** (как на других вкладках этой кухни), **полный набор вкладок** этой кухни с выделенной «Ингредиенты», пергамент с центрированным заголовком **«ИНГРЕДИЕНТЫ»**.

2. **Given** загружен контент ингредиентов  
   **When** список отображается  
   **Then** элементы показаны **сеткой** (ориентир — **3 колонки** на типичной ширине телефона в портрете; при узкой ширине допускается 2 колонки по правилам адаптива из `vdd-cookbook-layout-cook`).

3. **Given** элемент списка  
   **When** он отрисован  
   **Then** слева **квадратное превью**, справа **название на русском** (и локализованные строки из пайплайна для других языков приложения позже); карточка визуально согласована с карточкой блюда (`CookbookGridCard`).

4. **Given** для данной вкладки в контенте задано **несколько страниц** (`pageCount` > 1)  
   **When** пользователь на пергаменте  
   **Then** видна **панель пагинации** (стрелка назад, «**N из M**», стрелка вперёд); недоступные направления неактивны или скрыты по решению UX, но состояние не ломает вёрстку.

5. **Given** контент не загрузился  
   **When** ошибка сети или отсутствует запись  
   **Then** сообщение об ошибке и действия «Повторить» / «Назад» в стиле книги.

### Желательно

- Поиск по подстроке в названии ингредиента на текущей странице.
- Озвучивание семантики для VoiceOver / TalkBack («Ингредиент: …»).

## Ограничения

- Единый каркас с **`vdd-cookbook-layout-cook`** (`RegionalCuisineShell`).
- Источник правды по составу списков — контент книги (XML/JSON), без дублирования длинных списков в коде виджетов.

## Открытые вопросы

- [ ] Нужен ли тап по карточке ингредиента → модальное описание или переход в энциклопедия-страницу XML.
- [ ] Точное соответствие «страниц» пагинации изданию vs произвольное разбиение по N элементов.
