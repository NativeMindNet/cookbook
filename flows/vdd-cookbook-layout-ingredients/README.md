# Вкладка «Ингредиенты» в разделе кухни (VDD)

Кратко для заказчика:

## Что это

Экран **справочника ингредиентов** выбранной региональной кухни (Индия, Китай, Япония, Тайланд): тот же «книжный» каркас, что и у списков блюд — бамбук, цветной баннер кухни, ряд вкладок, пергамент с заголовком **«ИНГРЕДИЕНТЫ»** и сеткой карточек «миниатюра + название». Открывается выбором вкладки **Ингредиенты** внутри хаба кухни.

Это **не** мастер подсказок «чем заменить продукт»: мастер замены описан в **`flows/vdd-cookbook-layout-ingredients-replacement/`**.

## Как пользоваться документом разработки

1. [01-requirements.md](./01-requirements.md) — требования и приёмка.  
2. [02-visual.md](./02-visual.md) — ASCII, особенности по регионам и **описание экранов печатной книги на русском** (развороты «Индийская кухня — Ингредиенты» по референсным сканам).  
3. [03-specifications.md](./03-specifications.md) — данные, маршруты, Flutter.  
4. [04-plan.md](./04-plan.md) — задачи реализации.

## Связанные потоки

- **`flows/vdd-cookbook-layout-cook/`** — общий хаб кухни и каркас R0–R5.  
- **`flows/vdd-cookbook-layout/`** — ридер страницы рецепта (при необходимости перехода из других мест).  
- **`flows/vdd-cookbook-layout-ingredients-replacement/`** — замена ингредиентов из главного меню книги.
