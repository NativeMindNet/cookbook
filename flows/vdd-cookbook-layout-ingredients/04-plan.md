## Кратко

Подключить вкладку **Ингредиенты** внутри уже запланированного хаба кухни: загрузка страниц списка из контента, общая сетка карточек, пагинация по данным.

## Задачи

| ID | Задача | Проверка |
|----|--------|----------|
| I1 | Контракт `IngredientListPage` + маппинг из XML/JSON для 4 кухонь | Юнит-тест на образце фрагмента |
| I2 | Вкладка `ingredients` в конфиге табов для каждой `cuisineId` | Ручной проход всех четырёх |
| I3 | Экран/виджет списка на базе `RegionalCuisineShell` | Соответствие `02-visual.md` |
| I4 | `PaginationBar` и подстановка страницы | «N из M» на тайском примере |
| I5 | Ошибка / пусто / загрузка | Состояния из требований |
| I6 | Документация маршрута в общем роутере | Ссылка из `vdd-cookbook-layout-cook` согласована |

## Зависимости

- Задачи **C12–C15** из `vdd-cookbook-layout-cook/04-plan.md` (каркас и карточка) желательно выполнить раньше или параллельно с I3.
