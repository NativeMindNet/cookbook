# Требования: макеты экранов книги «Вегетарианская кухня Востока»

> Версия: 1.1  
> Статус: DRAFT  
> Обновлено: 2026-05-02  
> Язык документации: русский

## Проблема

Базовый поток `vdd-cookbook-layout` описывает **универсальный ридер** (свайпы, поиск, аудио). Не хватает зафиксированных **именно книжных экранов** в стилистике оригинального издания и **приложенных макетов экранов разделов кухонь**: обложка, меню разделов, вводные развороты пергамента, таблица мер, энциклопедические списки, а также **хаб региональной кухни** — баннер с названием кухни, вкладки категорий, пергамент с сеткой карточек «фото + подпись». Нужны явные связки: вкладка **«Ингредиенты»** в хабе → поток **`vdd-cookbook-layout-ingredients`**; плитка **«Замена ингредиентов»** в главном меню → **`vdd-cookbook-layout-ingredients-replacement`**.

## Пользовательские истории

### Основные

**Как** читатель  
**Я хочу** видеть обложку и главное меню книги в узнаваемом «восточном» оформлении  
**Чтобы** приложение ощущалось как цифровое продолжение печатной книги

**Как** читатель  
**Я хочу** открывать введение и оглавление тем с той же структурой, что в референсе (колонки, иллюстрации)  
**Чтобы** быстро находить нужный образовательный блок

**Как** читатель  
**Я хочу** открыть **«Замена ингредиентов»** из главного меню и попасть в **мастер** подсказок по аналогам  
**Чтобы** готовить без редких продуктов (см. `vdd-cookbook-layout-ingredients-replacement`)

### Вторичные

**Как** читатель  
**Я хочу** видеть справочный экран **мер ёмкостей** (стаканы ↔ мл/г)  
**Чтобы** переводить рецепты в домашнюю кухню

**Как** читатель на планшете/десктопе  
**Я хочу** видеть **разворот в две колонки** там, где это есть в макете  
**Чтобы** использовать широкий экран как открытую книгу

**Как** читатель  
**Я хочу** после выбора **Индийской / Китайской / Японской / Тайской** кухни попадать на экран с **тем же визуальным языком**, что на референсных скринах (орнаментальный фон, бамбук, цветной баннер названия кухни, «папки»-вкладки, пергамент)  
**Чтобы** раздел ощущался как страница книги, а не как «голый» список

**Как** читатель  
**Я хочу** переключать **категории блюд** вкладками и видеть **сетку карточек** с квадратной миниатюрой слева и названием справа  
**Чтобы** быстро выбирать рецепт внутри кухни

**Как** читатель  
**Я хочу** на некоторых экранах видеть **несколько подзаголовков-секций** на одном пергаменте (например закуски + салаты + супы), если так сверстан контент в книге  
**Чтобы** соответствие изданию сохранялось

### Хаб кухни — особенности по регионам (из референсов)

| Кухня | Вкладки | Примечание |
|-------|---------|------------|
| Индийская | Одна строка: Основные, Закуски, Салаты, Карри, Супы, **Ингредиенты** | Красный баннер «Индийская кухня». Контент вкладки «Ингредиенты» → **`vdd-cookbook-layout-ingredients`**. |
| Китайская | Одна строка: Основные, Салаты, Супы, Закуски, Десерты, **Ингредиенты** | Синий баннер «Китайская кухня». На части экранов — несколько секций с заголовками капсом на одном пергаменте. |
| Японская | Одна строка: Основные блюда, Соусы, **Ингредиенты** | Серый баннер «Японская кухня». На «Основные» возможны две секции (основные + соусы) по макету. |
| Тайская | **Две строки**: верх — Соусы и пасты / Салаты / Закуски; низ — Основные / Карри / Супы / Напитки / Десерты / **Ингредиенты** | Зелёный баннер «Тайская кухня». Активная вкладка визуально «вросла» в пергамент; там же возможна **пагинация** («N из M» и стрелки). |

## Критерии приёмки

### Обязательно

1. **Given** запуск приложения / вход в раздел книги  
   **When** показывается стартовый слой книги  
   **Then** доступна **обложка** (или splash → обложка) с заголовком «вегетарианская кухня востока», центральной фотозоной в бамбуковой раме, подзаголовком про кухни, брендингом внизу — по структуре референса.

2. **Given** пользователь на главном меню книги  
   **When** отображается сетка  
   **Then** есть **6 целей**: «Введение», «Замена ингредиентов», «Индийская», «Китайская», «Японская», «Тайская» кухня; верхние две визуально отделены («свитки на бамбуке»), нижние четыре — карточки с иллюстрацией и цветным баннером.

3. **Given** раздел «Введение»  
   **When** открыто оглавление  
   **Then** экран повторяет логику референса: пергамент, бамбук сверху, **две колонки тем** и **врезки фото** между блоками (минимум три зоны иллюстраций).

4. **Given** образовательный разворот (диета / продукты / питательность)  
   **When** пользователь листает  
   **Then** контент может быть **в одну колонку на телефоне** или **в две колонки на широком экране**, с общими элементами: тёмная орнаментальная подложка, «висячие» страницы пергамента, заголовки капсом, нумерованные списки.

5. **Given** экран «Меры ёмкостей»  
   **When** он открыт из введения / справочника  
   **Then** слева (или сверху на узком экране) таблица объёмов и переводов «1 стакан ↔ граммы» для ключевых ингредиентов; справа (или ниже) блок с **двумя фото** как в референсе.

6. **Given** экран «Знаменитые вегетарианцы»  
   **When** показывается список  
   **Then** категории (мыслители, деятели, музыканты и т.д.) и **зебра-строки** для читаемости на пергаменте.

7. **Given** пункт «Замена ингредиентов» в меню  
   **When** пользователь нажимает  
   **Then** выполняется переход к потоку **`vdd-cookbook-layout-ingredients-replacement`** (мастер), без дублирования полной спецификации мастера в этом документе.

8. **Given** пользователь в хабе любой из четырёх кухонь из п.2 меню  
   **When** отображается экран категории  
   **Then** видны: мелкий заголовок серии **«Вегетарианская кухня Востока»**, декоративная перекладина/бамбук, **цветной баннер** с локализованным названием кухни (красный / синий / серый / зелёный по региону), **вкладки** в конфигурации таблицы выше, **пергаментная** основная зона с заголовком секции капсом (напр. «ОСНОВНЫЕ БЛЮДА») и **сеткой из карточек** (квадратное превью + текст).

9. **Given** выбрана вкладка с длинным списком (напр. тайские основные блюда)  
   **When** контент разбит на страницы по данным книги  
   **Then** внизу пергамента отображается **пагинация** в стиле макета («N из M», стрелки назад/вперёд); жест и кнопки не конфликтуют с системной «назад».

10. **Given** вкладка **«Ингредиенты»** в хабе кухни  
    **When** пользователь её открывает  
    **Then** применяется тот же каркас хаба (баннер, вкладки, пергамент), заголовок **«ИНГРЕДИЕНТЫ»**, сетка элементов «миниатюра + название»; детальные требования и пагинация по страницам списка — в **`vdd-cookbook-layout-ingredients`**.

### Желательно

- Сохранение пропорций безопасных зон под вырезы экрана и жест «назад» в стиле книги.
- Локализация строк меню и заголовков согласована с `vdd-cookbook-layout` (мультиязычие позже; **референсы на русском**).

### Не входит в этот VDD

- Полная верстка всех 400+ рецептных страниц XML (остаётся в общем ридере).
- Запись пользовательских заметок в PDF.

## Ограничения

- Согласованность с **`vdd-cookbook-layout`**: те же Bloc/навигация/ориентации.
- Производительность: тяжёлые фоны и текстуры — через кэш изображений / ограничение разрешения на mobile.
- Контент текстов — из контент-пайплайна книги (XML/HTML), не хардкод простыней в виджетах (допускаются временные заглушки в имплементации).
