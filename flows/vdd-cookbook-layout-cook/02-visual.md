## Общая дизайн-система (из референсов)

| Элемент | Описание |
|---------|----------|
| Фон обложки | Бордо/кирпичный, орнамент «турецкий огурец» / пейсли |
| Акцент | Золото/бронза на заголовках |
| Меню | Тёмно-коричневый фон, повторяющийся цветочный узор |
| Страницы | Пергамент бежевый, тёмная рама; сверху **бамбуковый шест с кольцами** |
| Карточки кухонь | Иллюстрация сверху + цветной баннер с названием |
| Типографика | Сериф для заголовков; основной текст контрастный, тёплый коричневый |

### Хаб региональной кухни (общие элементы по скринам)

| Элемент | Описание |
|---------|----------|
| Фон | Тёмно-коричневый с повторяющимся орнаментом (дамасск / «цветок»). |
| Верх слева | Мелко: «Вегетарианская кухня Востока». |
| Баннер | Прямоугольник на «подвесе» с бамбуковой перекладины и кольцами; цвет баннера задаётся кухней (Индия — красный; Китай — синий; Япония — серый; Тай — зелёный). Крупный белый декоративный заголовок названия кухни. |
| Вкладки | Светлый пергамент/«папки» с фактурой; активная вкладка светлее и нижним краем смыкается с основной панелью. |
| Панель контента | Большой светлый пергамент с декоративным краем; сверху по центру заголовок секции **КАПСОМ** (напр. «ОСНОВНЫЕ БЛЮДА», «ИНГРЕДИЕНТЫ»). |
| Карточка пункта | Горизонтальный блок: **квадратное фото слева**, справа название на пергаментном фоне; слегка «рваные» или скруглённые края. |
| Тайланд | Две строки вкладок; опционально строка пагинации у нижнего края («N из M», ‹ ›). |

## Экран R0: Общая сетка хаба кухни (рецепты или секции)

```
+------------------------------------------+
| Вегетарианская кухня Востока      (мелко)|
| ===== бамбук + кольца =================|
| |:::::::: НАЗВАНИЕ КУХНИ (banнер) :::::|   <- цвет по региону
| ========================================|
| [ Вкладка 1 ][ Вкладка 2*][ Вкладка 3 ]...   <- * активная
| +--- пергамент --------------------------+|
| |           ЗАГОЛОВОК СЕКЦИИ           ||
| | +------+ +------+ +------+             ||
| | |[img]|Текст |[img]|Текст |[img]|Текст ||   <- 3 колонки
| | +------+ +------+ +------+             ||
| |   ... сетка по данным XML ...          ||
| +----------------------------------------+|
| [ ‹  2 из 3  › ]    <- только если пагинация|
+------------------------------------------+
```

Для **Тайской** кухни над строкой вкладок из примера добавить **вторую строку** вкладок (см. требования).

## Экран R1: Индийская кухня — пример вкладки «Ингредиенты»

Одна строка вкладок: Основные | Закуски | Салаты | Карри | Супы | **Ингредиенты***.

Контент: заголовок **ИНГРЕДИЕНТЫ**, сетка **3×N** карточек «нутовая мука», «тамаринд», … (полный перечень и страницы — из данных книги; референс — скрин с 24 позициями).

Подробности экрана ингредиентов — **`vdd-cookbook-layout-ingredients`**.

---

## Экран R2: Китайская кухня — вкладка «Основные»

Синий баннер «Китайская кухня». Вкладки: Основные* | Салаты | Супы | Закуски | Десерты | Ингредиенты.

Пергамент: **ОСНОВНЫЕ БЛЮДА**, сетка 3 колонки; внизу возможна строка с **двумя** карточками по центру (как на референсе).

---

## Экран R3: Китайская кухня — составной пергамент (несколько секций)

На одном пергаменте блоки с подзаголовками **ЗАКУСКИ**, **САЛАТЫ**, **СУПЫ**, **ДЕСЕРТЫ** — каждый со своей подсеткой карточек (соответствует макету с группировкой категорий на одном экране).

---

## Экран R4: Японская кухня — «Основные блюда» + секция соусов

Серый баннер «Японская кухня». Три вкладки: **Основные блюда*** | Соусы | Ингредиенты.

На активной вкладке основных: сначала блок **ОСНОВНЫЕ БЛЮДА** (сетка; последняя строка может содержать одну центрированную карточку), ниже блок **СОУСЫ** с отдельным заголовком и сеткой.

---

## Экран R5: Тайская кухня — двухрядные вкладки и пагинация

Зелёный баннер «Тайская кухня».

```
        ряд 1: [ Соусы и пасты ][ Салаты ][ Закуски ]
        ряд 2: [ Основные* ][ Карри ][ Супы ][ Напитки ][ Десерты ][ Ингредиенты ]
```

Примеры контента по скринам: отдельные пергаменты для **ОСНОВНЫЕ БЛЮДА**, **КАРРИ**, **СУПЫ**, **ЗАКУСКИ**, объединённые **НАПИТКИ + ДЕСЕРТЫ**, вкладка «Соусы и пасты» может совмещать секции **СОУСЫ И ПАСТЫ** и **САЛАТЫ** на одном пергаменте.

Пагинация: например «1 из 3» / «2 из 3» / «3 из 3» для длинных списков внутри вкладки.
