## Общая дизайн-система

| Элемент | Описание |
|---------|----------|
| Фон обложки | Бордо/кирпичный, орнамент «турецкий огурец» / пейсли |
| Акцент | Золото/бронза на заголовках |
| Меню | Тёмно-коричневый фон, повторяющийся цветочный узор |
| Страницы | Пергамент бежевый, тёмная рама; сверху **бамбуковый шест с кольцами** |
| Карточки кухонь | Иллюстрация сверху + цветной баннер с названием |
| Типографика | Сериф для заголовков; основной текст контрастный, тёплый коричневый |

### Цвета баннеров по кухням

| Кухня | Цвет баннера |
|-------|--------------|
| Индия | Красный / бордо |
| Китай | Синий |
| Япония | Серый |
| Тайланд | Зелёный |

## Компонент: Карточка блюда/ингредиента

```
+----------------------------------+
| +----------------------------+   |
| |                            |   |
| |   [ квадратное фото ]      |   |
| |       блюда / ингр.        |   |
| |        1:1 ratio           |   |
| |                            |   |
| +----------------------------+   |
|                                  |
|  Название блюда / ингредиента    |
|  (1-2 строки, по центру)         |
+----------------------------------+

Размеры:
- Фото: 1:1 (квадрат), скруглённые или «рваные» края
- Карточка: ~180-220px ширина
- Отступы: 8-12dp
- Фон: пергамент с лёгкой текстурой
```

---

## Компонент: Строка пагинации

```
+--------------------------------------------------+
|        [ ‹ ]     N из M     [ › ]                |
+--------------------------------------------------+

- ‹ / › — кнопки «назад» / «вперёд»
- При N=1 кнопка ‹ неактивна
- При N=M кнопка › неактивна
- Индикатор по центру
```
