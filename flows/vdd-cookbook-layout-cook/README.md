# Книга «Вегетарианская кухня Востока» — оболочка экранов (VDD)

Кратко для заказчика:

## Что это

Набор экранов визуальной книги в стилистике приложенных макетов (RU):

- **Оболочка серии**: обложка, главное меню, оглавление введения, образовательные развороты, меры ёмкостей, знаменитые вегетарианцы.
- **Хабы региональных кухонь**: экраны «книги» после выбора **Индийской / Китайской / Японской / Тайской** кухни — бамбук, цветной баннер названия кухни, вкладки категорий, пергаментная панель с сеткой карточек (миниатюра слева + подпись справа). Отдельные варианты вкладок и состав контента зафиксированы в `02-visual.md`.

Технический просмотр отдельной страницы рецепта остаётся в общем потоке **`vdd-cookbook-layout`**.

**Вкладка «Ингредиенты»** внутри хаба кухни (справочный список ингредиентов региона, не мастер замен) описана в **`flows/vdd-cookbook-layout-ingredients/`**.

## Как пользоваться документом разработки

1. [01-requirements.md](./01-requirements.md) — что должно быть на экранах.
