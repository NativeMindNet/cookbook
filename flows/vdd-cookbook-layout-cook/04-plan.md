# План реализации: vdd-cookbook-layout-cook

> Версия: 1.1  
> Статус: DRAFT  
> Обновлено: 2026-05-02  
> Спецификации: [03-specifications.md](./03-specifications.md)

## Кратко

Ввести тему «Восток», декоративные виджеты (пергамент, бамбук), экраны обложки и меню, оглавление введения и шаблоны разворотов; **хабы региональных кухонь** (вкладки, сетка карточек, опционально двухрядные вкладки и пагинация); подключить переход в модуль мастера замены ингредиентов, в **`vdd-cookbook-layout-ingredients`** для вкладки ингредиентов и в существующий ридер рецептов.

## Задачи

### Фаза 1: Тема и примитивы

| ID | Задача | Файлы (ориентир) | Проверка |
|----|--------|-------------------|----------|
| C1 | Цвета, типографика, тени пергамента | `lib/theme/cook_east_theme.dart` | Визуальное сравнение с референсом |
| C2 | `ParchmentPanel`, `BambooRodHeader` | `lib/widgets/book_decor/` | Unit/widget smoke |
| C3 | Фоновые слои (бордо + узор) | assets + `DecorationImage` | Нет мигания при первом кадре |

### Фаза 2: Экраны навигации

| ID | Задача | Проверка |
|----|--------|----------|
| C4 | Обложка + CTA | Deep link `/book` открывает обложку |
| C5 | Меню 6 плиток | Все шесть маршрутов ведут к заглушке или реальному экрану |
| C6 | Оглавление введения | Ссылки скроллят к якорям или пушат `spreadId` |

### Фаза 3: Контентные шаблоны

| ID | Задача | Проверка |
|----|--------|----------|
| C7 | Шаблон разворота с колонками | Tablet 2 col / phone 1 col |
| C8 | Экран мер | Таблица + блок фото |
| C9 | Экран «Знаменитые» | Зебра + категории |

### Фаза 4: Интеграция

| ID | Задача | Проверка |
|----|--------|----------|
| C10 | Навигация в `go_router` | Полный цикл Cover→Menu→Intro→Reader |
| C11 | Плитка «Замена ингредиентов» → модуль VDD ingredients-replacement | Открывается мастер |

### Фаза 5: Хаб региональной кухни

| ID | Задача | Проверка |
|----|--------|----------|
| C12 | `RegionalCuisineShell` + палитра баннера по `cuisineId` | Сверка с `02-visual` R0 |
| C13 | Однорядные вкладки (Индия, Китай, Япония) | Переключение без моргания фона |
| C14 | Двухрядные вкладки + связка активной пары (Тайланд) | Поведение как на референсе |
| C15 | `CookbookGridCard` + сетка 3 колонки (адаптив при узкой ширине) | Golden или ручной чек |
| C16 | Составной пергамент (несколько `SectionBlock`) | Китайский составной экран |
| C17 | Пагинация списка внутри вкладки | Стрелки и «N из M» |
| C18 | Вкладка «Ингредиенты» → делегирование экрана по **`vdd-cookbook-layout-ingredients`** | Один каркас, общие карточки |

## Риски

| Риск | Митигация |
|------|-----------|
| Размер текстур | WebP / растровые превью для mobile |
| Дублирование с ридером | Общий `BookTypography` из одного файла |

## Откат

Удалить маршруты `book/*` и тему; оставить базовый ридер без изменений.
