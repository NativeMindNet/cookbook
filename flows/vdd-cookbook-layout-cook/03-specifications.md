# Спецификации: макеты книги «Вегетарианская кухня Востока»

> Версия: 1.1  
> Статус: DRAFT  
> Обновлено: 2026-05-02  
> Визуал: [02-visual.md](./02-visual.md)

## Обзор

Техническое описание экранной оболочки книги, согласованной с референсами и с базовым ридером `vdd-cookbook-layout`. Контент страниц приходит из существующего XML; **экранные шаблоны** задают композицию, тему и навигацию.

Дополнение **v1.1**: **хаб региональной кухни** — общий каркас (`RegionalCuisineShell`) для экранов R0–R5: баннер цвета региона, одно- или двухрядные вкладки, пергамент с заголовком секции и сеткой **`CookbookGridCard`** (квадратный `Image` + подпись). Составной пергамент (несколько секций на одном экране) — список блоков `SectionBlock(title, items)` в модели представления. Экран вкладки **«Ингредиенты»** использует тот же каркас и карточку; доменные правила и пагинация списка ингредиентов — в **`vdd-cookbook-layout-ingredients`**.

## Затронутые системы

| Компонент | Изменения |
|-----------|-----------|
| Flutter UI | Новые экраны-оболочки + тема `CookBookEastTheme` (цвета, декоративные виджеты); хаб кухни — `RegionalCuisineShell`, вкладки, сетка карточек |
| Роутинг | Маршруты `/book/cover`, `/book/menu`, `/book/intro/toc`, `/book/spread/:id`, `/book/measures`, `/book/famous`; **`/book/cuisine/:cuisineId/tab/:tabId`** (опц. query **`page`** для пагинации списков); замена ингредиентов → другой модуль; вкладка **`tabId=ingredients`** → **`vdd-cookbook-layout-ingredients`** |
| Контент | Маппинг `spreadId` / `sectionId` на фрагменты XML или HTML |
| Ресурсы | Фоновые текстуры, бамбук (SVG/PNG), локализованные строки меню |

## Архитектура UI

### Слои

1. **Shell**: глобальный фон (бордо / коричневый узор), безопасные отступы.
2. **ScrollPage**: пергамент с тенью и скруглениями; опционально «две страницы» через `Row` + `LayoutBuilder`.
3. **BambooHeader**: повторяемый декоративный элемент под заголовком серии.
4. **InsetPhotos**: 1–3 изображения с соотношением сторон из референса.
5. **RegionalCuisineShell**: подпись серии, стержень бамбука, **BannerPlaque** (`cuisineId` → палитра акцента), **TabStrip** (один или два ряда), слот **ParchmentBody** (скролл).
6. **CookbookGridCard**: `AspectRatio(1)` для превью + расширяемая область текста; `InkWell` / семантика для доступности.
7. **PaginationBar** (опционально): только для кухонь и категорий, где в данных задано несколько страниц списка (типовой кейс — Тайланд).

### Адаптивность

| Ширина | Поведение |
|--------|-----------|
| `< 600` | Одна колонка; «разворот» = последовательные секции |
| `≥ 600` | Две колонки для TOC и разворотов |
| `≥ 900` | Увеличенные поля, возможное фиксирование max-width пергамента |

## Маршруты и данные

| Экран | Назначение | Источник данных |
|-------|------------|-----------------|
| Cover | Маркетинг + вход | Локализованные строки + asset обложки |
| Menu | Навигация | Статический конфиг шести плиток + deep link |
| Intro TOC | Список тем | XML оглавление или конфиг ссылок на `pageId` |
| Spreads | Образовательные блоки | Контент по `spreadId` |
| Measures | Таблица | Локализованная таблица (JSON/CSV в assets) или XML |
| Famous | Списки имён | Контент-пакет |
| Cuisine hub | Категория внутри кухни | XML / конфиг: список вкладок, для каждой — секции и элементы (`recipeId` или `ingredientId`), опц. `pageIndex`, `pageCount` |
| Вкладка «Ингредиенты» в хабе | Справочник региона | **`vdd-cookbook-layout-ingredients`** |
| Мастер замены | Плитка главного меню | **`vdd-cookbook-layout-ingredients-replacement`** |

## Поведение

- **Назад**: из любого экрана книги — возврат к предыдущему стеку; из меню — к обложке или выход в корень приложения (как решит продукт).
- **Переход к ридеру рецептов**: плитки региональных кухонь открывают **хаб** (`RegionalCuisineShell`) с первой вкладкой по умолчанию; тап по карточке рецепта — в сценарий `vdd-cookbook-layout` с `pageId` из данных.
- **Вкладка «Ингредиенты»**: навигация внутри хаба без смены каркаса; модель списка и UX пагинации — см. **`vdd-cookbook-layout-ingredients`**.

## Ошибки и краевые случаи

| Ситуация | Действие |
|----------|----------|
| Нет asset текстуры | Fallback однотонный цвет из палитры |
| Пустой XML блока | Экран ошибки + лог |
| Очень длинный текст | `SingleChildScrollView` / вертикальный пагинг при интеграции с ридером |

## Зависимости

- Требует утверждённых маршрутов deeplink (`sdd-cookbook-route-deeplink`) для прямых ссылок на разделы книги (опционально в следующей итерации).
- Требует базового `vdd-cookbook-layout` для страниц рецептов.

## Тестирование

- Golden-тесты ключевых экранов (cover, menu, toc) на одном размере + скролл smoke.
- Контраст текста WCAG AA на пергаменте.
