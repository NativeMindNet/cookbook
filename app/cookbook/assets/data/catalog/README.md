# Каталог контента (`catalog/`)

Папка — **машиночитаемый пакет** для потока `flows/sdd-cookbook-content`: строки спецификации `02-specifications.md` (§3–§14) вынесены в JSON.

## Индекс

Состав перечислен в **`catalog_index.json`** (`bundles[]`: `id` → файл → сущность SDD).

## Свод по кухням (§13)

- **`cuisine_indian.json`**, **`cuisine_chinese.json`**, **`cuisine_japanese.json`**, **`cuisine_thai.json`** — формат, удобный для экранов хаба (вкладки, панели).
- **`cuisine_hubs.json`** — объединённое дерево всех кухонь с вкладками, секциями пергамента, пагинацией и списками карточек по SDD §13 (для импорта, тестов и сверки с `book.xml`).
- **`indian_main_recipes.json`** — структурированные рецепты (ингредиенты, шаги, метаданные) для блюд с фонами `079.png`–`091.png` и доп. скана фаршированной тыквы; маппинг в **`book_xml_mapping_indian_mains.json`**.

## Путь `data/assets` в корне репозитория

В корне cookbook каталог **`data/assets`** указывает сюда же (symlink), чтобы в документации SDD можно было ссылаться как на `data/assets/…`.
